## 🌟 ප්‍රධාන විශේෂාංග (Key Features)

### 1. ⌨️ යතුරුකරණ ක්‍රම 3ක් (3 Typing Modes)
- **Smart Phonetic (සිංග්ලිෂ්)**: ඉංග්‍රීසි අකුරුවලින් සිංහල ශබ්ද ලියන විට ස්වයංක්‍රීයව නිවැරදි සිංහල අකුරු බවට පරිවර්තනය වේ (උදා: `ammaa` ➔ `අම්මා`, `oyaata` ➔ `ඔයාට`).
- **Phonetic (ශබ්දානුකූල)**: සම්මත ශබ්දානුකූල සිංග්ලිෂ් පරිවර්තනය.
- **Wijesekara (විජේසේකර)**: සම්මත SLS ශ්‍රී ලංකා ජාතික විජේසේකර යතුරුපුවරු ආකෘතිය (රකාරාංශය, යංශය, ඇ-ඈ ස්වර නිවැරදිව සහය දක්වයි).

### 3. 🌐 ක්ෂණික පරිවර්තකය (Instant Translate Bar)
- **Sinhala ⇄ English පරිවර්තනය**: ටයිප් කරන අතරතුරම යතුරුපුවරුව තුළින්ම (In-Keyboard) සිංහලෙන් ඉංග්‍රීසියට හෝ ඉංග්‍රීසියෙන් සිංහලට ක්ෂණිකව පරිවර්තනය කළ හැක.
- **High-Contrast Dark Theme**: ඕනෑම කීබෝඩ් තීම් එකකදී පවා අකුරු පැහැදිලිව පෙනෙන පරිදි ස්ථිර Dark UI එකක් සහිතය.
- **Quick Phrases**: නිතර භාවිතා වන කෙටි වැකි (Greetings, Questions ආදී) ක්ෂණිකව පරිවර්තනය කර යැවීමේ පහසුකම.

## 🚀 යතුරුපුවරුව සක්‍රිය කරගන්නා ආකාරය (How to Enable)

1. ඔබගේ දුරකථනයේ **Slashboard** යෙදුම විවෘත කරන්න.
2. **Enable slashboard** තට්ටු කර Android Keyboard Settings වෙත ගොස් **slashboard Sinhala** සක්‍රිය (Turn ON) කරන්න.
3. නැවත යෙදුමට පැමිණ **Select active keyboard** තට්ටු කර **slashboard Sinhala** තෝරන්න.
