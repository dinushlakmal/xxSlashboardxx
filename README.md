## 🌟 ප්‍රධාන විශේෂාංග (Key Features - v3.0.1)

### 1. ⚡ Zero-Lag High Performance Typing Engine
- **Ultra Smooth Response**: යතුරු එබීමේදී ක්ෂණික ප්‍රතිචාරය (Instant 0-latency input) ලබාදීම සඳහා බරැති පසුබිම් animations ඉවත් කර සකසා ඇත.
- **Precision Key Gaps**: යතුරු අතර පරතරය පරිශීලකයාට අවශ්‍ය පරිදි සකස් කරගත හැක (Default: Horizontal 0.5dp, Vertical 5.8dp).
- **Low-RAM Performance Scaling**: 2GB සහ 4GB RAM ඇති දුරකථනවල පවා කිසිදු ඇනහිටීමක් (Lag) නැතිව සුමටව ධාවනය වේ.

### 2. ⌨️ යතුරුකරණ ක්‍රම (Typing Modes)
- **Smart Phonetic (සිංග්ලිෂ්)**: ඉංග්‍රීසි අකුරුවලින් සිංහල ශබ්ද ලියන විට ස්වයංක්‍රීයව නිවැරදි සිංහල අකුරු බවට පරිවර්තනය වේ (උදා: `ammaa` ➔ `අම්මා`, `oyaata` ➔ `ඔයාට`).
- **Phonetic (ශබ්දානුකූල)**: සම්මත ශබ්දානුකූල සිංග්ලිෂ් පරිවර්තනය.
- **Wijesekara (විජේසේකර)**: සම්මත රාජ්‍ය විජේසේකර ලේඅවුට් එකෙන් පහසුවෙන් යතුරු ලියනය කිරීමේ පහසුකම.
