Activate Slashboard in three simple steps — zero personal data collection.

01

Enable in System Settings

Slashboard App එක විවෘත කර "Enable Slashboard" බොත්තම ඔබා Android On-Screen Keyboard ලැයිස්තුවෙන් Slashboard ක්‍රියාත්මක කරන්න.

Settings → System → Languages & Input
02

Switch Input Method

"Select Input Method" බොත්තම ඔබා ඔබගේ ප්‍රධාන යතුරුපුවරුව ලෙස Slashboard තෝරන්න.

Default Keyboard: Slashboard IME
03

Choose Mode & Emoji Pack
